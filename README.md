# Stores Sales Analysis Dashboard

This project contains a **Power BI dashboard** for analyzing sales performance across multiple stores. The dashboard provides insights into sales trends, performance by date, and other key metrics, helping decision-makers visualize data effectively.

## 📊 Dashboard Features

- **Sales Overview**: View total sales, trends over time, and sales percentage per store.
- **Interactive Filters**: Filter by date, store, and product category for detailed insights.
- **Visual KPIs**: Key performance indicators like total sales, growth percentages, and time-based analysis.
- **Time-Intelligent Analytics**: Yearly and overall growth calculations using Power BI time intelligence.
- **Randomized Time Data**: Simulated time-based sales events with minimum gaps to emulate realistic store transactions.

## ⚙️ Tools Used

- **Microsoft Power BI Desktop** – for building the dashboard and implementing DAX measures.

## 📝 How to Use

1. Download the **Power BI PBIX file** from the Drive link.  
2. Open it in **Power BI Desktop**.  
3. Explore the dashboard using the slicers and visuals.  
4. Optionally, replace the sample data with your own store sales data for a live analysis.
